# skySupport UI preview

Live preview:

- Agent console: https://yaswanthramp.github.io/skysupport-preview/
- Customer portal: https://yaswanthramp.github.io/skysupport-preview/portal.html
- Workforce Lifecycle: https://yaswanthramp.github.io/skysupport-preview/workforce.html

Switch product from the Service Desk / Workforce Lifecycle control in the header.
Switch role from the profile menu, top right, under Portal view.

Static UI wireframes of a redesigned service desk, covering both products and both roles.
Each page is a single self-contained HTML file: no build step, no external requests, typeface
embedded. Pages follow the viewer's system light or dark setting, with a manual toggle.

All figures are illustrative sample data.

## Screens

Agent console (9 views): Overview, Tickets, Ticket detail, Portals, Create portal,
Contacts, Organisations, Reports, Settings.

Customer portal (7 views): Portals, one portal, New request, My requests, Request detail,
Approvals, Knowledge base.

Workforce Lifecycle, admin (13 views): Dashboard, People, Lifecycle, Start onboarding,
Learning, Create workflow, Workflow detail, Access, Assets, Licences, Reports, Settings,
Connect a portal.

Learning covers the training automation engine: a workflow catalogue, a rule builder with
live match preview, deadline and email configuration, progress analytics with the four
status stages, and the skyLearn course catalogue.

## Scope

Visual preview only. Navigation, view switching, tabs, and dialogs work. Sorting, filtering,
pagination, and form controls switch visual state but are not wired to data.
